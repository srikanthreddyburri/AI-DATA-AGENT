# 🤖 AI Data Quality Agent

An AI-powered data quality analysis platform that automatically profiles datasets, detects quality issues, generates quality scores, visualizes insights, and provides AI recommendations.

## 🚀 Features

- CSV Dataset Upload
- Automated Data Profiling
- Missing Value Detection
- Duplicate Detection
- Outlier Analysis
- Constant Column Detection
- Data Quality Score
- Data Visualization
- AI Generated Data Quality Report using Ollama
